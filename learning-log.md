## 2.1 Переменные

- Переменная представляет именованный участок памяти, который может хранить **значение** определенного **типа данных**

Для определения переменной применяется ключевое слово **var**, после которого идет имя переменной, а затем указывается ее тип:

- var имя_переменной тип_данных

**В Go можно объявлять переменные следующими способами:**

- var имя_переменной тип_переменной

- var имя_переменной тип_переменной = значение_переменной

- var имя_переменной = значение_переменной

- имя_переменной := значение_переменной // тип переменной выводится исходя из ее значения

- имя_переменной_1, имя_переменной_2 := значение_переменной_1, значение_переменной_2

- var имя_переменной_1, имя_переменной_2 тип_переменных   // все переменные имеют один тип

- var (
    имя_переменной_1 тип_переменной_1
    имя_переменной_2 тип_переменной_2
)

- var (
    имя_переменной_1  = значение_переменной_1
    имя_переменной_2 = значение_переменной_2
)

Например, простейшее определние переменной:

- var hello string

Можно объявить сразу несколько переменных через запятую:

- var a, b, c string

**При объявлении переменной можно сразу присвоить ей значение. Такой прием называется инициализацией:**

- var hello string = "Hello"

**Краткое определение переменной:**

- имя_переменной := значение
- name := "Tom"

    В этом случае тип данных явным образом не указывается, он выводится автоматически из присваиваемого значения. Ограничением такого способа является то, что его можно использовать только внутри функции.

## 2.2 Типы данных

Все данные представляют набор битов, и именнно тип данных определяет, как будут итерпретироваться эти данные и какие операции с ними можно производить.

- Язык Go является статически типизированным, то есть все используемые в программе данные имеют определенный тип.

### Целочисленные типы

- int8: представляет целое число от -128 до 127 и занимает в памяти 1 байт (8 бит)

- int16: представляет целое число от -32768 до 32767 и занимает в памяти 2 байта (16 бит)

- int32: представляет целое число от -2147483648 до 2147483647 и занимает 4 байта (32 бита)

- int64: представляет целое число от –9 223 372 036 854 775 808 до 9 223 372 036 854 775 807 и занимает 8 байт (64 бита)

- uint8: представляет целое число от 0 до 255 и занимает 1 байт

- uint16: представляет целое число от 0 до 65535 и занимает 2 байта

- uint32: представляет целое число от 0 до 4294967295 и занимает 4 байта

- uint64: представляет целое число от 0 до 18 446 744 073 709 551 615 и занимает 8 байт

- byte: синоним типа uint8, представляет целое число от 0 до 255 и занимает 1 байт

- rune: синоним типа int32, представляет целое число от -2147483648 до 2147483647 и занимает 4 байта

- int: представляет целое число со знаком, которое в зависимости о платформы может занимать либо 4 байта, либо 8 байт. То есть соответствовать либо int32, либо int64.

- uint: представляет целое беззнаковое число только без знака, которое, аналогично типу int, в зависимости о платформы может занимать либо 4 байта, либо 8 байт. То есть соответствовать либо uint32, либо uint64.

### Числа с плавающей точкой

- float32: представляет число с плавающей точкой от 1.4*10-45 до 3.4*1038(для положительных). Занимает в памяти 4 байта (32 бита)

- float64: представляет число с плавающей точкой от 4.9*10-324 до 1.8*10308 (для положительных) и занимает 8 байт.

### Комплексные числа

- complex64: комплексное число, где вещественная и мнимая части представляют числа float32

- complex128: комплексное число, где вещественная и мнимая части представляют числа float64

### Тип bool

- Логический тип или тип **bool** может иметь одно из двух значений: **true**(истина) или **false**(ложь).

### Строки

- Строки представлены типом **string**. В Go строке соответствует строковый литерал - последовательность сивмолов, заключенная в двойные кавычки.

- Причем строки в Go - это не просто набор символов, а своеобразная структура данных - байтовый срез, доступный только для чтения. Каждый байт в строке представляет часть символа в кодировке UTF-8, которая является кодировкой переменной длины и которая может представлять любой символ Unicode. Строки в Go неизменяемы, что означает, что после создания строки ее содержимое нельзя изменить напрямую.

**Наиболее распространенные последовательности:**

- \n: переход на новую строку

- \r: возврат каретки

- \t: табуляция

- \": двойная кавычка внутри строк

- \\: обратный слеш

### Значение по умолчанию

- Для числовых типов: число 0

- Для логического типа: false

- Для строк: ""(пустая строка)

### Неявная типизация

При определении переменной мы можем опускать тип в том случае, если мы явно инициализируем переменную каким-нибудь значением:

- var name = "Tom"

## 2.3 Константы

Для определения констант применяется ключевое слово const:

- const pi float64 = 3.1415

В отличие от переменной мы не можем изменить значение константы.

- const pi float64 = 3.1415
- pi = 2.7182             // ! Ошибка

Константы можно инициализировать только константными значениями, например, литералами типа чисел или строк, или значениями других констант. Но инициализировать константу значением переменной мы не можем:

`var m int = 7`

`// const k = m      // ! Ошибка: m - переменная`

`const s = 5     // Норм: 5 - числовая константа`

`const n = s     // Норм: s - константа`

### Автоматическая инициализация контсант

Если определяется последовательность констант, то инициализацию значением можно опустить для всех констант, кроме первой. В этом случае константа без значения получит значение предыдущей константы:

- const (
    a = 1
    b
    c
    d = 3
    f
)
- fmt.Println(a, b, c, d, f)      // 1, 1, 1, 3, 3

### iota-идентификатор

Go поддерживает идентификатор **iota**, который увеличивается с объявлением каждой новой константы. Всякий раз, когда компилятор получает блок const, идентификатор iota сбрасывается до нуля и увеличивается на единицу после каждой непустой строки в блоке const.

## 2.4 Различные операции

### Арифметические операции

- `+`: Операция сложения возвращает сумму двух чисел

- `-`: Операция вычитания возвращает разность двух чисел

- `*`: Операция умножения возвращает произведение двух чисел

- `/`: Операция деления двух чисел

- `%`: Возвращает остаток от деления (в этой операции могут принимать участие только целочисленные операнды)

- `x++`: Постфиксный инкремент (x++). Увеличивает значение переменной на единицу

- `x--`: Постфиксный декремент (x--). Уменьшает значение переменной на единицу

### Операции сравнения

- `==`: Операция "равно". Возвращает true, если оба операнда равны, и false, если они не равны

- `>`: Операция "больше чем". Возвращает true, если первый операнд больше второго, и false, если первый операнд меньше второго

- `<`: Операция "меньше чем". Возвращает true, если первый операнд меньше второго, и false, если первый операнд больше второго

- `<=`: Операция "меньше или равно". Возвращает true, если первый операнд меньше или равен второму, и false, если первый операнд больше второго

- `>=`: Операция "больше или равно". Возвращает true, если первый операнд больше или равен второму, и false, если первый операнд меньше второго

- `!=`: Операция "не равно". Возвращает true, если первый операнд не равен второму, и false, если оба операнда равны

### Логические операции

- `!`: операция отрицания. Инвертирует значение. Если операнд равен true, то возвращает false, иначе возвращает true

- `&&`: конъюнкция, логическое умножение. Возвращает true, если оба операнда не равны false. Возвращает false, если хотя бы один операнд равен false

- `||`: дизъюнкция, логическое сложение. Возвращает true, если хотя бы один операнд не равен false. Возвращает false, если оба операнда равны false

### Поразрядные операции

- `<<`: Сдвигает битовое представление числа, представленного первым операндом, влево на определенное количество разрядов, которое задается вторым операндом

- `>>`: Сдвигает битовое представление числа вправо на определенное количество разрядов

### Операции присвоения

- `=`: Присваивает левому операнду значение правого операнда

- `:=`: Присваивает левому операнду, который ранее не был определен, значение правого операнда

- `+=`: Присваивает левому операнду сумму значений левого и правого операнда

- `-=`: Присваивает левому операнду разность значений левого и правого операнда

- `*=`: Присваивает левому операнду произведение значений левого и правого операнда

- `/=`: Присваивает левому операнду результат деления значений левого операнда на правый

- `%=`: Присваивает левому операнду результат остатка от деления значений левого операнда на правый

- `<<=`: Присваивает левому операнду результат сдвига влево значения левого операнда на значение правого операнда

- `>>=`: Присваивает левому операнду результат сдвига вправо значения левого операнда на значение правого операнда

- `&=`: Присваивает левому операнду результат побитового умножения левого и правого операндов

- `^=`: Присваивает левому операнду результат операции XOR между левым и правым операндами

- `|=`: Присваивает левому операнду результат побитового сложения левого и правого операндов

## 2.5 Массивы

Массивы представляют последовательность элементов определенного типа. Массив определяется следующим способом:

- `var numbers [число элементов]тип элементов`

Наример, массив из пяти элементов типа int:

- `var numbers [5]int`

- Здесь все элементы инициализируются значениями по умолчанию => numbers это [0 0 0 0 0]

Можно инициализировать массив со значениями:

- `var numbers [5]int = 5[int]{1,2,3,4,5}`

Если в квадратных скобках вместо длины указано троеточие, то длина массива определяется, исходя из количества переданных ему элементов:

- `var number = [...]int{1,2,3,4,5} // длина массива 5`
- `numbers2 := [...]int{1,2,3} //длина массива 3`

### Индексы

Для обращения к элементам массива применяются индексы - номера элементов. При этом нумерация начинается с нуля, то есть первый элемент будет иметь индекс 0. Индекс указывается в квадратных скобках. По индексу можно получить значение элемента, либо изменить его.

`var numbers 5[int] = [5]int{1,2,3,4,5}`
`fmt.Println(numbers[0]) //1`
`fmt.Println(numbers[4]) //5`
`numbers[0]=87`
`fmt.Println(numbers[0]) //87`

Индексы в массиве фактически выступают в качестве ключей, по которым можно обратиться к соответствующему значению. И в принципе мы можем явным образом указать, какому ключу какое значение будет соответствовать. При этом числовые ключи необязательно располагать в порядке возрастания:

- `colors := [3]string{2: "blue", 0: "red", 1: "green"}`
- `fmt.Println(colors[2]) //blue`

### Многомерные массивы

Кроме одномерных массивов мы можем определять и многомерные массивы, которые можно определить как массивы массива. Многомерный массив можно разбить на несколько одномерных массивов. В таких массивах данные хранятся в табличной форме (порядок по строкам). Размер многомерного массива определяется его размерами, которые равны произведению размеров всех размерностей.

Многомерные массивы объявляются следующим образом:

- `Имя_массива := [размерность_1][размерность_2]..тип_массива{значения_массива}`

### Длина массивов

Для получения длины массива Go предоставляет встроенную функцию len(), которая возвращает количество элементов массива

Для многомерных массивов функция len() возвращает размер только первой размерности массива.

### Сравнение массивов

Два массива называются равными, если они оба имеют одинаковый тип и размер, имеют одинаковые элементы, и все элементы находятся в одинаковом порядке в обоих массивах. Для сравнения массивов применяется стандартный оператор сравнения ==. Он возвращает true, если оба массива равны, в противном случае false. Сначала он проверяет тип данных обоих массивов, а затем сопоставляет значения по индексу.

### Копирование массива

Копирование массива — это просто присвоение одного массива другому. Поскольку в Go массив ведет себя как значение, а не как ссылка, то изменение любого значения одного массива не оказывает никакого влияния на другой.

## 2.6 Условные конструкции

### if...else

Конструкция if принимает условие - выражение, которое возвращает значение типа bool. И если это условие истинно, то выполняется последующий блок инструкций.

Условие ставится после оператора if.

- Если условное выражение оператора if истинно, то выполняется if, если ложно - выполняется блок после else.

- Если необходимо проверить несколько альтернативных вариантов, то можно добавить выражения else if

### switch

Конструкция switch проверяет значение некоторого выражения. С помощью операторов case определяются значения для сравнения. Если значение после оператора case совпадает со значением выражения из switch, то выполняется код данного блока case.

Также конструкция switch может содержать необязательный блок default, который выполняется, если ни один из операторов case не содержит нужного значения.

## 2.7 Циклы

Циклы позволяют в зависимости от определенного условия выполнять некоторые действия множество раз. Фактически в Go есть только один цикл - цикл for, который может принимать разные формы.

Определение цикла:

- `for [инициализация счетчика]; [условие]; [изменение счетчика] {действия}`

Нам не обязательно указывать все условия при объявлении цикла. Например, можно вынести объявление переменной вовне:

- `var i = 1`
- `for ; i < 10; i++ {fmt.Println(i*i)}`

Можно убрать изменение счетчика в само тело цикла и оставить только условие:

- `var i = 1`
- `for ; i < 10; {fmt.Println(i*i) i++}`

### Вложенные циклы

Циклы могут быть вложенными, то есть располагаться внутри других циклов.

### Перебор наборов данных

Ряд типов данных представляют набор данных. Например, строка может быть представлена как набор символов. Кроме того, в Go есть комплексные типы, которые представляют колллекции данных, в частности, массивы, срезы, словари. Для перебора наборов данных в языке Go есть специальная форма цикла for:

- `for индекс, значение := range набор данных {действия}`

Если мы не планируем использовать значения или индексы элементов, то мы можем вместо них указать прочерк.

### Операторы break и continue

Может возникнуть ситуация, когда нам надо при определенных условиях завершить текущую итерацию цикла, не выполнять все инструкции цикла, а сразу перейти к следующей итерации. В этом случае можно использовать оператор **continue**.

Оператор **break** используется для немедленного выхода из цикла (как правило, при определенном условии)

Опертор **break** нередко применяется для выхода из вложенных циклов. Для этого оператору передается метка - на нее проецируется цикл, из которого надо выйти.

## 3.1 Функции и их параметры

Функция представляет собой блок операторов, которые все вместе выполняют какую-то определенную задачу. С помощью функций можно многократно вызывать ее блок операторов как единое целое в других частях программы.

Функция объвляется так:

- `func имя_функции (список параметров) (типы_возвращаемых_значений) {выполняемые_операторы}`

Функция определяется с помощью ключевого слова func, после которого идет имя функции.

Название функции вместе с типами ее параметров и типами возвращаемых значений еще называют **сигнатурой**

По умолчанию каждая программа на языке Go должна содержать как минимум одну функцию - **main**, которая является входной точкой в приложение.

Для вызова функции пишется ее имя, после которого в скобках указываются значения для параметров функции.

### Параметры функции

Через параметры функция получает входные данные. Параметры указываются в скобках после имени функции. Для каждого параметра указывается имя и тип (как для переменной).

Друг от друга параметры разделяются запятыми.

В качестве аргументов при вызове функции можно передавать и значения переменных, результаты операций или других функций, но при этом следует учитывать, что аргументы в функцию всегда передаются по значению.

### Неопределенное количество параметров

В Go функция может принимать неопределнное количество параметров одного типа.

Для определения параметра, который представляет неопределенное количество значений, перед типом этих значений ставится многоточие: numbers ...int. То есть через подобный параметр мы получаем несколько значений типа int.

## 3.2 Возвращение результата из функции

Функции могут возвращать результат. Для этого нужно после списка параметров функции указать тип возвращаемого результата.А в теле функции использовать оператор return, после которого указывается возвращаемое значение

- `func имя_функции (список параметров) тип_возвращаемого значение {выполняемые_операторы return возвращаемое_значение}`

### Именованные возвращаемые результаты

Возвращаемые результат может быть именован:

- `func add(x, y int) (z, int) {}`

### Возвращение нескольких значений

В Go функция может возвращать сразу несколько значений. В этом случае после списка параметров указываетя в скобках список типов возвращаемых значений. А после оператора return располагаются через запятую все возвращаемые значения.

## 3.3 Тип функции. Функция как параметр и результат функции

Каждая функция имеет определенный тип, который складывается из списка типов параметров и списка типов возвращаемых результатов.

Нам важно знать какой тип имеет функция, так как мы можем определять переменные или парамтеры функций, которые будут представлять определенный тип функции. Например:

Функция:

- `func add (x int, y int) int(return x + y)`

Можно определить в функции main() переменную так:

- `var f func(int, int) int = add`

А потом вызвать внутри fmt.Println():

- `fmt.Println(f(3,5))`

### Функции как параметры других функций

Также функция может передаваться в качестве параметра в другую функцию

Например:

- `func action (n1 int, n2 int, operation func(int, int) int)`

В данном случае функция action принимает три параметра. Первые два параметра - числа, а третий параметр - функция, которая соответствует типу: func(int, int) int

### Функция как результат другой функции

Функция также может возвращаться из другой функции в качестве результата

Например:

- `func add(x int, y int) int {return x+y}`
- `func selectFn(n int) (func(int, int) int) {return add}`

Здесь мы возвращаем в функции selectFn другую функцию add

### Анонимные функции

Анонимные функции (также иногда называются лямбдами) - функции, которым не назначено имя. Они отличаются от обычных функций тем, что могут они могут определяться внутри других функций и также могут иметь доступ к контексту выполнения.

Анонимные функции позволяют нам определить некоторое действие непосредственно там, где оно применяется.

### Замыкания

Замыкание (closure) представляет объект функции, который запоминает свое лексическое окружение даже в том случае, когда она выполняется вне своей области видимости.

Технически замыкание включает три компонента:

- внешняя функция, которая определяет некоторую область видимости и в которой определены некоторые переменные и параметры - лексическое окружение
- переменные и параметры (лексическое окружение), которые определены во внешней функции
- вложенная функция, которая использует переменные и параметры внешней функции

В языке Go замыкания реализуются с помощью анонимных функций, поскольку анонимные функции имеют доступ к окружению, в котором они определяются.

Например:

```
func outer() func() {
    var n int
    inner := func() {

    }
    return inner
}
```

Замыкание на простейшем примере:

```
package main
import "fmt"
  
func outer() func(){       // внешняя функция
    var n int = 5        // некоторая переменная - лексическое окружение функции inner
    inner := func(){     // вложенная функция
        // действия с переменной n
        n += 1
        fmt.Println(n)
    }
    return inner
}
  
func main() {
      
    fn := outer()   // fn = inner, так как функция outer возвращает функцию inner
    // вызываем внутреннюю функцию inner
    fn()   // 6
    fn()   // 7
    fn()   // 8
}
```

## 4.1 Указатели

**Указатели** представляют собой объекты, значением которых служат адреса других объектов (например, переменных). Так, когда мы объявляем переменную, компилятор Go выделяет некоторое пространство в системной памяти в соответствии с типом этой переменной.

Пример указателя на объект типа int:

- `var p *int`

Этому указателю можно присвоить адрес переменной типа int. Для получения адреса применяется операция &, после которой указывается имя переменной (&x).

```
package main
 
import "fmt"
 
func main() {
     
    var x int = 4       // определяем переменную
    var p *int          // определяем указатель 
    p = &x              // указатель получает адрес переменной
    fmt.Println(p)      // значение самого указателя - адрес переменной x
}
```

Если мы попробуем вывести адрес переменной на консоль, то увидим, что он представляет шестандцатеричное значение:

`0xc0420120a0`

По адресу, который хранит указатель, мы можем получить значение переменной x. Для этого применяется операция разыменования (*). Результатом этой операции является значение переменной на которую указывает указатель.

```
package main
 
import "fmt"
 
func main() {
     
    var x int = 4
    var p *int  = &x                // указатель получает адрес переменной
    fmt.Println("Address:", p)      // значение указателя - адрес переменной x
    fmt.Println("Value:", *p)       // значение переменной x
}
```

Консольный вывод:
`Address: 0xc0420c058`
`Value: 4`

Используя указатель, мы можем менять значение по адресу, который хранится в указателе:

```
var x int = 4
var p *int = &x
*p = 25
fmt.Println(x)      // 25
```

### Пустой указатель

Если указатлю не присвоен адрес какого-либо объекта, то такой указатель по умолчанию имеет значение **nil** (по сути отсутствие значения). Если мы попробуем получить значение по такому пустому указателю, то мы столкнемся с ошибкой.

Поэтому при работе с указателями иногда бывает целесообразно проверять на значение nil:

```
var pf *float64
if pf != nil{
    fmt.Println("Value:", *pf)
}
```

### Функция new

Переменная представляет именованный объект в памяти. Язык Go также позволяет создавать безымянные объекты - они также размещаются в памяти, но не имеют имени как переменные. Для этого применяется функция new(type). В эту функию передается тип, объект которого надо создать. Функция возвращает указатель на созданный объект.

### Указатели на указатели

Указатель может хранить адрес переменной, таким образом, указывая на эту переменную. Но, поскольку указатель сам определяется как обычная переменная и точко также имеет адрес в памяти (просто значение этого адреса - адрсе другой переменной), то указатели также могут хранить адреса других указателей.

Например:

```
package main
import "fmt"
 
func main() {
 
    var a int = 9
 
    var p_a *int = &a   // p_a - указатель на переменную a
 
    // обращаемся к указателю p_a
    fmt.Println("Value of a:", *p_a)     // Value of a: 9
    fmt.Println("Address of a:", p_a)  // Address of a: 0xc000010100
 
    var p_p_a **int = &p_a   // p_p_a - указатель на переменную p_a
 
    // обращаемся к указателю p_a
    fmt.Println("Value of p_a:", *p_p_a)     // Value of p_a: 0xc000010100
    fmt.Println("Address of p_a:", p_p_a)  // Address of p_a: 0xc000076040
}
```

### Массивы указателей

В языке Go мы можем создать массив указателей, которые содержат адрес значений одного и того же типа данных

```
package main
import "fmt"
 
func main() {
 
    var a, b, d int = 1, 2, 4
 
    var p_nums[4] *int   // массив из 4 указателей на значения типа int
 
    p_nums[0] = &a 
    p_nums[1] = &b 
    p_nums[3] = &d
 
    fmt.Println(p_nums) // [0xc000010100 0xc000010108 <nil> 0xc000010110]
}
```

## 4.2 Указатели и функции

- Указатели как параметры функции

По умолчанию все параметры передаются в функцию по значению. Например:

```
package main
import "fmt"
 
func changeValue(x int){
    x = x * x
}
func main() {
     
    d := 5
    fmt.Println("d before:", d)     // 5
    changeValue(d)                  // изменяем значение
    fmt.Println("d after:", d)      // 5 - значение не изменилось
}
```

Функция changeValue изменяет значение параметра, возводя его в квадрат. Но после вызова этой функции мы видим, что значение переменной d, которая передается в changeValue, не изменилось. Ведь функция получает копию данной переменной и работает с ней независимо от оригинальной переменной d. Поэтому d никак не изменяется.

Однако, если нам надо менять значение передаваемой переменной. В этом случае мы используем указатели:

```
package main
 
import "fmt"
 
func changeValue(x *int){
    *x = (*x) * (*x)
}
func main() {
     
    d := 5
    fmt.Println("d before:", d)     // 5
    changeValue(&d)                 // изменяем значение
    fmt.Println("d after:", d)      // 25 - значение изменилось!
}
```

### Указатель как результат функции

Функция может возвращать указатель:

```
package main
import "fmt"
 
func createPointer(x int) *int{
    p := new(int)
    *p = x
    return p
}
 
func main() {
     
    p1 := createPointer(7)
    fmt.Println("p1:", *p1)     // p1: 7
    p2 := createPointer(10)
    fmt.Println("p2:", *p2)     // p2: 10
    p3 := createPointer(28)
    fmt.Println("p3:", *p3)     // p3: 28
}
```

В данном случае функция createPointer возвращает указатель на объект int.


## 5.1 Псевдонимы

Оператор **type** позволяет определять для некоторого типа псевдоним. Псевдоним не представляет новый тип, а лишь определяет новое название для уже существующего типа. Например:

- `type mile uint`

В данном случае для типа uint определяется псевдоним mile, который основывается на типе uint. По сути mile представляется тип uint и работа с ним будет производиться также, как и с типом uint. Однако в то же время фактически это новый тип.

Мы можем определять переменные данного типа, работать с ними как с объектами базового типа

Для чего?

1. Где мы должны явно указать, что будет использовать данный тип (по смыслу и логике)
2. Для скоращения названия типов в том случае, если они слишком длинные или громоздкие


## 5.2 Структуры

**Структуры** представляют собой составной тип данных, определяемый разработчиком и служащий для представления каких-либо объектов. Структуры содержат набор полей, которые представляют различные атрибуты объекта. Для определения структуры применяются ключевые слова **type** и **struct**:

```
type имя_структуры struct{
    поле1 тип_поля1 
    поле2 тип_поля2
    ...............
    полеN тип_поляN
}
```

Каждое поле имеет название и тип данных, как переменная. Например, структура, которая представляет человека:

```
type human struct {
    name string
    age int
}
```

Если структура имеет поля одного типа, то их можно совместить. Например, так:

```
type human struct {
    name, gender string
    age int
}
```

Мы можем определять структуру как вне функций на так называемом верхнем уровне файла, так и внутри функций.

### Создание структуры

Структура представляет новый типы данных, и мы можем определить переменную данного типа:

`var tom person`

И тогда 

```
package main
import "fmt"
 
type person struct{
    name string
    age int
}
 
func main() {
 
    var tom person   // переменная структуры person
    fmt.Println(tom) // { 0}
}
```

Хотя мы не присвоили переменной никакого значения, ее поля получают некоторые значения по умолчанию. Например, для строковых поле - это пустая строка, а для числовых - это число 0.

### Инициализация структуры

С помощью инициализатора можно передать структуре начальные значения:

`var tom person = person{"Tom", 23}`

Инициализация представляет набор значений в фигурных скобках. Причем эти значения передаются полям структуры в том порядке, в котором поля определены в структуре. Например, в данном случае строка "Tom" передается первому полю - name, а второе значение - 23 передается второму полю - age.

Например, выведем структуру после инициализации на консоль:

```
package main
import "fmt"
 
type person struct{
    name string
    age int
}
 
func main() {
 
    var tom person = person{"Tom", 23}
    fmt.Println(tom) // {Tom 23}
}
```

1. Мы можем явно образом указать какие значения передаются свойствам:
`var alice person = person{age: 23, name: "Alice"}`
2. Также можно использовать сокращенное способы инициализации переменной структуры:
`var tom = person {name: "Tom", age: 24}`
`bob := person {name: "Bob", age: 31}`
3. Можно даже не указывать никаких значений, в этом случае свойства структуры получат значения по умолчанию:
`undefined := person {}  // name - пустая строка, age - 0`

### Обращение к полям структуры

Для обращения к полям структуры после переменной ставится точка и указывается поле структуры:

```
package main
import "fmt"
 
type person struct{
    name string
    age int
}
 
func main() {
     
    var tom = person {name: "Tom", age: 24}
    fmt.Println(tom.name)       // Tom
    fmt.Println(tom.age)        // 24
     
    tom.age = 38    // изменяем значение
    fmt.Println(tom.name, tom.age)      // Tom 38
}
```

### Анонимные структуры

Необязательно объявлять новый тип при объявлении структур. Мы также можем создать анонимную структуру в языке Go, как показано в следующем коде:

```
package main
import "fmt"
 
var tom struct{
    name string
    age int
}
func main() {
 
    tom.name = "Tom"
    tom.age =  23
    fmt.Println(tom.name) // Tom
    fmt.Println(tom.age) // 23
}
```

Также мы можем сразу инициализировать переменную анонимной структуры:

```
package main
import "fmt"
 
func main() {
 
    tom := struct{  // объявление переменной анонимной структуры
        name string
        age int
    }{              // инициализация переменной
        name: "Tom",
        age: 41,
    }
 
    fmt.Println(tom.name) // Tom
    fmt.Println(tom.age) // 41
}
```

При таком использовании определение структуры происходит внутри функции.

### Анонимныек поля структур

В языке Go нет необходимости определять имя полей структуры. Если мы укажем только тип поля, то тип будет считаться именем этого поля.

```
package main
import "fmt"
  
type person struct{
    string
    int
}
  
func main() {
      
    tom := person {"Tom", 41}
    fmt.Println(tom)    // {Tom 41}
}
```

Если у нас есть два или более полей одного типа данных, мы можем использовать только одно поле как анонимное. Для остальных мы должны указать имена полей.


```
package main
import "fmt"
  
type person struct{
    string
    string      // Ошибка: string redeclared - other declaration of string
 
    int
}
  
func main() {
      
    tom := person {"Tom", "Google", 41}
    fmt.Println(tom)    // {Tom 41}
}
```

Соответственно в этом случае нам надо указать имя для второго строкового поля, чтобы не сталкиваться с этой ошибкой:

```type person struct{
    string
    company string
    int
}
```

### Указатели на структуры

Как и в случае с обычными переменными, можно создавать указатели на структуры, которые будут хранить адрес структур:

```
tom := person {name: "Tom", age: 22}
var p_tom *person = &tom  // p_tom - указатель на стркутуру
```

Для инициализации указателя на структуру необязательно присваивать ему адрес переменной. Можно присвоить адрес безымянного объекта следующим образом:

`var tom *person = &person{name:"Tom", age:23}`

Для доступа к полям структуры через указатель нам достаточно поcле имени указателя через точку указать название поля:

```
package main
import "fmt"
  
type person struct{
    name string
    age int
}
  
func main() {
      
    tom := person {name: "Tom", age: 22}
    var p_tom *person = &tom  // p_tom - указатель на 
 
    // обращаемся к полям структуры через указатель
    fmt.Println(p_tom.name)        // Tom
    fmt.Println(p_tom.age)        // 22
 
    p_tom.age = 23  // меняем значение поля через указатель
    fmt.Println(tom.age)        // 23
}
```

Такой синтаксис прост и интуитивен. Однако для обращения к полям структуры через указатель также можно использовать операцию разыменования.

```
package main
import "fmt"
  
type person struct{
    name string
    age int
}
  
func main() {
      
    tom := person {name: "Tom", age: 22}
    var p_tom *person = &tom  // p_tom - указатель на 
 
    // обращаемся к полям структуры через разыменование указателя
    fmt.Println((*p_tom).name)        // Tom
    fmt.Println((*p_tom).age)        // 22
 
    (*p_tom).age = 23 
    fmt.Println(tom.age)        // 23
}
```

Таким образом, у нас есть два способа обращения к полям структуры через указатель:
```
p_tom.age
(*p_tom).age
```
Также можно определять указатели на отдельные поля структуры:
```
tom := person {name: "Tom", age: 22}
var p_age *int = &tom.age   // указатель на поле tom.age
*p_age = 35         // изменяем значение поля
fmt.Println(tom.age)        //  35
```

### Функция new

Структуру также можно создать с помощью функции new(). Эта функция выделяет пространство памяти в соответствии с размером полей структуры и возрващает указатель на него. Изначально все поля имеют значения по умолчанию, если они не заданы.

``` 
package main
import "fmt"
  
type person struct{
    name string
    age int
}
  
func main() {
      
    tom := new(person) 
 
    fmt.Println(*tom) // { 0} 
 
    tom.name = "Tom"
    tom.age = 41
    fmt.Println(*tom)   // {Tom 41}
 
    // анонимная структура с new
    bob := new(struct{ name, company string; age int})
 
    fmt.Println(*bob) // {  0}
 
    bob.name = "Bob"
    bob.company = "Google"
    bob.age = 46
 
    fmt.Println(*bob) // {Bob Google 46}
}
```

### Копирование структур

При копировании одной структуры в другую создается новая копия, которая затем присваивается другой переменной:

```
package main
import "fmt"
  
type person struct{
    name string
    age int
}
 
func main() {
      
    tom := person {"Tom",  41,}
 
    tomas := tom  // копирование структуры tom
    tomas.age = 18
 
    // изменение одной структуры никак не влияет на другую
    fmt.Println(tom.age)    // 41
    fmt.Println(tomas.age)  // 18
}
```

### Передача структур в функции

Структура может выступать в качестве параметра функции. В этом случае при передаче структуры в функцию передается копия структуры:

```
package main
import "fmt"
  
type person struct{
    name string
    age int
}
 
func increment_age(user *person){
    user.age += 1
    fmt.Println(*user)   // {Tom 42}
}
 
func main() {
      
    tom := person {"Tom",  41,}
    // в функцию передается адрес структуры tom
    increment_age(&tom)
     
    // изменение структуры внутри функции по указателю приведет к изменению оригинальной структуры
    fmt.Println(tom)    // {Tom 42}
}
```

### Сравнение структур

При сравнении структур они считаются равными, если их поля и соответствующие значения одинаковы:

```
package main
import "fmt"
  
type person struct{ 
    name string
    age int
}
 
func main() {
      
    tom := person {"Tom",  41}
    bob := person {"Bob",  41}
    tomas := person {"Tom",  41}
 
    fmt.Println("tom == bob:", tom == bob)  // tom == bob: false
    fmt.Println("tom == tomas:", tom == tomas)  // tom == tomas: true
}
```

## 5.3 Структуры как поля других структур

Язык Go позволяет определять поля структур как значения других структур. В этом случае мы имеем дело с **вложенными** и **встроенными структурами**:

- **Вложенные структуры** (nested struct) определяются как именованные поля внутри другой структуры, и доступ к их полям осуществляется с использованием имени поля внешней структуры.

- **Встроенные структуры** (embeded struct) определяются без имени поля, что продвигает их поля во внешнюю структуру для прямого доступа. Встроенные структуры предлагают более чистый синтаксис, но могут вызывать конфликты имен.

Пример вложенных структур:

```
package main
import "fmt"
  
type person struct{  // вложенная структура person
    name string
    age int
}
 
type account struct{
    login string
    password string
 
    person_info person
}
  
func main() {
      
    tom := account{
        login: "tom@hmail.com",
        password: "12345678",
        person_info: person {
            name: "Tom", 
            age: 41,
        },
    } 
 
    fmt.Println(tom)    // {tom@hmail.com 12345678 {Tom 41}}
 
    // обращение к полям вложенной структуры
    fmt.Println("Name: ", tom.person_info.name) // Name: Tom
}
```

В данном случае поле person_info в структуре account представляет структуру person

Пример встроенной структуры:

```
package main
import "fmt"
  
type person struct{  // вложенная структура person
    name string
    age int
}
 
type account struct{
    login string
    password string
    person
}
  
func main() {
      
    tom := account{
        "tom@hmail.com",
        "12345678",
        person {"Tom",  41,},
    } 
 
    fmt.Println(tom)    // {tom@hmail.com 12345678 {Tom 41}}
 
    // обращение к полям встроенной структуры
    fmt.Println("Name: ", tom.person.name) // Name: Tom
}
```
Данный пример во многом аналогичен предыдущему, только теперь явным образом не определяется название поле в структуре account, которое представляет структуру person. А для обращения к полям встроенной структуры применяется ее имя.

### Хранения ссылки на структуру того же типа

При этом надо учитывать, что структура не может иметь поле, которое представляет тип этой же структуры. Например:

```type node struct{
    value int
    next node
}
```

Подобное определение будет неправильным. Вместо этого поле должно представлять указатель на структуру:

```
package main
import "fmt"
 
type node struct{
    value int
    next *node
}
 
// рекурсивный вывод списка
func printNodeValue(n *node){
     
    fmt.Println(n.value)
    if n.next != nil{
        printNodeValue(n.next)
    }
}
func main() {
     
    first := node{value: 4}
    second := node{value: 5}
    third := node{value: 6}
     
    first.next = &second
    second.next = &third
     
    var current *node = &first
    for current != nil{
        fmt.Println(current.value)
        current = current.next
    }
}
```

Здесь определена структура node, которая представляет типичный узел односвязного списка. Она хранит значение в поле value и ссылку на следующий узел через указатель next. 

В функции main создаются три связанных структуры, и с помощью цикла for и вспомогательноого указателя current выводятся их значения.

```
4
5
6
```

## 5.4 Методы

**Метод** представляет функцию, связанную с определенным типом. Методы определяются также как и обычные функции за тем исключением, что в определении метода также необходимо указать получателя или receiver. Получатель - это параметр того типа, к которому прикрепляется метод:
```
func (имя_параметра тип_получателя) имя_метода (параметры) (типы_возвращаемых_результатов){
    тело_метода
}
```
Допустим, у нас будет определен именованный тип, представляющий срез из строк:
```
type library []string
``` 
Для вывода всех элементов из среза мы можем определить следующий метод:
```
func (l library) print(){
 
    for _, val := range l{
        fmt.Println(val)
    }
}
```
Та часть, которая расположена между ключевым словом func и именем метода и представляет определение получателя, для которого будет определен этот метод: (l library). Используя параметр получателя (в данном случае l), мы можем обращаться к получателю. Например, в нашем случае получатель представляет срез - набор объектов. С помощью цикла for можно пройтись по этому срезу и вывести все его элементы на консоль.

Поскольку print представляет именно метод, который определен для типа library, а не обычную функцию, то мы можем вызвать этот метод у любого объекта типа library:
```
var lib library = library{ "Book1", "Book2", "Book3" }
lib.print()
```
lib является объектом типа library, поэтому для него мы можем вызвать метод print. В данном случае объект lib - это и будет то значение, которое будет передаваться в функцию print через параметр (l library). Полный пример:
```
package main
import "fmt"
 
type library []string
 
func (l library) print(){
  
    for _, val := range l{
        fmt.Println(val)
    }
}
func main() {
      
    var lib library = library{ "Book1", "Book2", "Book3" }
    lib.print()
}
```

### Методы стркутур

Подобным образом мы можем определять методы для структур:
```
package main
 
import "fmt"
 
type person struct{
    name string
    age int
}
func (p person) print(){
    fmt.Println("Name:", p.name)
    fmt.Println("Age:", p.age)
}
 
func (p person) eat(meal string){
    fmt.Println(p.name, "eats", meal)
}
 
func main() {
     
    tom := person { name: "Tom", age: 24 }
    tom.print()
    tom.eat("apples")
}
```
Консольный вывод данной программы:
```
Name: Tom
Age: 24
Tom eats apples
```
В данном случае для структуры person определены две функции: print и eat. Функция print выводит информацию о текущем объекте person. А функция eat имитирует употребление пищи.Каждая из этих функций определяет объект и тип структуры, к которой функция относится:
```
func (p person) имя_функции
```
С помощью объекта p мы можем обращаться к свойствам структуры person. В остальном это обычные функции, которые могут принимать параметры и возвращать результат.

Для обращения к функциям структуры указывается переменная структуры и через точку идет вызов функциии.
```
tom.print()
tom.eat("apples")
```

## 5.5 Методы указателей

При вызове метода, объект структуры, для которого определен метод, передается в него по назначению. Что это значит? Вот пример:
```
package main
import "fmt"
 
type person struct{
    name string
    age int
}
func (p person) update_age(new_age int){
    p.age = new_age
}
 
func main() {
     
    var tom = person { name: "Tom", age: 24 }
    fmt.Println("before", tom.age)
    tom.update_age(33)
    fmt.Println("after", tom.age)
}
```
Для структуры person определен метод update_age, который принимает параметр new_age и изменяет значение поля age у структуры. То есть при вызове этого метода мы ожидаем, что возраст человека изменится. Однако консольный вывод нам показывает, что значение поля age не изменяется:
```
before 24
after 24
```
Потому что при вызове tom.update_age(33) метод update_age получает копию структуры tom. То есть структура tom копируется в другой участок памяти, и далее метод update_age работает с копией, никак не затрагивая оригинальную структуру tom.

Но что если мы все таки хотим таким образом изменять состояние структуры? В этом случае необходимо использовать указатели на структуры:
```
package main
import "fmt"
 
type person struct{
    name string
    age int
}
func (p *person) update_age(new_age int){
    p.age = new_age
}
 
func main() {
     
    var tom = person { name: "Tom", age: 24 }
    var p_tom *person = &tom
    fmt.Println("before", tom.age)
    p_tom.update_age(33)
    fmt.Println("after", tom.age)
}
```
Теперь метод update_age принимает указатель на структуру person: p *person, то есть фактически адрес структуры в памяти. С помощью операции разыменования получаем значение по этому адресу в памяти и меняем поле age:

`p.age = new_age`

В функции main определяем указатель на структуру person и передаем ему адрес структуры tom:

`var p_tom *person = &tom`

Затем вызываем метод update_age:

`p_tom.update_age(33)`

Таким образом, метод update_age получит адрес, который хранится в p_tom и по этому адресу обратиться к структуре tom, изменив значение ее свойств age/

Стоит отметить, что несмотря на то, что метод update_age определен для указателя на структуру person, мы по прежнему можем вызывать этот метод и для объекта person^
```
var tom = person { name: "Tom", age: 24 }
fmt.Println("before", tom.age)      // before 24
tom.update_age(33)
fmt.Println("after", tom.age)       // after 33
```

## 5.6 Срезы

**Срезы (slice)** представляют последовательность элементов одного типа переменной длины. В отличие от массивов длина в срезах не фиксирована и динамически может меняться, то есть можно добавлять новые элементы или удалять уже существующие.

Срез определяется также, как и массив, за тем исключением, что у него не указывается длина:
```
var users []string
```
Также срез можно инициализировать значениями:
```
var users = ["Tom", "Alice", "Jordan"]
//или так
users_2 := []string{"Tom", "Alice", "Jordan"}
```

### Оператор среза и создания среза из последовательностей

Также можно создать срез из другой последовательности элементов, например, из массива. Для этого применяется оператор среза - **:** (двоеточие)
```
s[i:j]
```
Этому оператору нужно указать два индекса: начальный (i) и конечный (j) индексы массива, все элементы между которыми попадут в срез. Оператор среза создает из последовательности (например, из массива) s новый срез, который содержит элементы последовательности s с i по j-1. При этом должно соблюдаться условие 0 <= i <= j <= cap(s). В качестве исходной последовательности, из которой берутся элементы, может использоваться массив, указатель на массив или другой срез. В итоге в полученном срезе будет j-i элементов.

Если начальный индекс не указан, то по умолчанию применяется значение 0. Если конечный индекс не указан, то вместо него используется длина исходной последовательности s.
```
// исходный массив
initialUsers := [8]string{"Bob", "Alice", "Kate", "Sam", "Tom", "Paul", "Mike", "Robert"}
users1 := initialUsers[2:6]     // с 3-го по 6-й 
users2 := initialUsers[:4]      // с 1-го по 4-й
users3 := initialUsers[3:]      // с 4-го до конца
     
fmt.Println(users1)     // ["Kate", "Sam", "Tom", "Paul"]
fmt.Println(users2)     // ["Bob", "Alice", "Kate", "Sam"]
fmt.Println(users3)     // ["Sam", "Tom", "Paul", "Mike", "Robert"]
```
Другой пример - создание среза из строки:
```
package main
import "fmt"
 
func main() {
     
    str := "Hello World"
    slice := str[6:]
 
    fmt.Println(slice) // World
}
```

### Создание среза из другого среза

Мы также можем создать аналогичным образом новый срез из другого среза:
```
package main
import "fmt"
 
func main() {
     
    var array [7] int = [7] int {1, 2, 3, 4, 5, 6, 7} 
 
    slice1 := array[1:6]
    fmt.Println("slice from array:", slice1)  // slice from array: [2 3 4 5 6]
 
    slice2 := slice1[:3]
    fmt.Println("slice2 from slice1:", slice2)  // slice2 from slice1: [2 3 4]
}
```

### Обращение к элементам среза и перебор среза

К элементам среза обращение происходит также, как и к элементам массива - по индексу и также мы можем перебирать все элементы с помощью цикла for:
```
var users []string = []string{"Tom", "Alice", "Kate"}
fmt.Println(users[2])   // Kate
users[2] = "Katherine"
 
for _, value := range users{
    fmt.Println(value)
}
```

### Внутренняя реализация среза

Обычно срез состоит из указателя на сегмент массива, длины сегмента массива и максимума, до которого может быть расширен срез:

1. **Указатель**
    
    В реальности срезы не хранят никаких данных: они лишь ссылаются на массив или раздел базового массива. Инициализация среза из массива и изменение элементов массива также изменяют значение среза.Аналогично, изменение значения элемента среза отражает его ссылаемый массив. Например:
    ```
    import "fmt"
 
    func main() {
        
        array := [6] int {1, 2, 3, 4, 5, 6} 
        fmt.Println("Начальный массив:", array)  // [1 2 3 4 5 6]
    
        slice := array[1:5]
        fmt.Println("Начальный срез:", slice)  // [2 3 4 5]
    
        // изменяем второй элемент массива
        array[1] = 22
        // также меняется и срез
        fmt.Println("Срез после изменения в массиве:", slice)  // [22 3 4 5]
    
    
        // изменяем второй элемент среза
        slice[1] = 33
        // также меняется и массив
        fmt.Println("Массив после изменения в срезе:", array)  // [1 22 33 4 5 6]
    
    }
    ```

2. **Длина**
    
    Длина - это количество элементов, на которые ссылается срез. Как в случае с массивами, для получения длины среза применяется функция **len()**. Она возвращает общее количество элементов, которые содержит срез.
    ```
    package main
    import "fmt"
    
    func main() {
        
        array := [6] int {1, 2, 3, 4, 5, 6} 
        slice := array[1:5]
        fmt.Println("Длина среза:", len(slice))  // 4
    }
    ```

3. **Емкость** 

    Для одного и того же среза его длина и емкость могут быть одинаковыми или разными. Длина связана со срезом, в то время как емкость связана с массивом. Емкость среза — это количество элементов в базовом массиве, начиная с первого элемента среза. Это означает, что емкость среза относится к размеру, до которого может быть расширен срез. Для получения емкости применяется функция cap():
    ```
    package main
    import "fmt"
 
    func main() {
        
        array := [6] int {1, 2, 3, 4, 5, 6} 
        slice := array[1:5]
        fmt.Println("Емкость среза:", cap(slice))  // 5
    }
    ```
    


## 6.1 Пакеты и модули

- Весь код в языке Go организуется в пакеты. Пакет представляют удобную организацию разделения кода на отдельные части или модули. Физически пакет — это просто каталог/папка, которая содержит несколько файлов с исходным кодом на Go. Импортируя пакет, мы можем использовать функциональность его файлов многократно в различных программах.

- Модуль в языке Go представляет коллекцию пакетов, который имеет встроенное версионирование и который можно опубликовать для использования в других проектах. Применение модулей в Go имеет ряд преимуществ:

    1. Изоляция зависимостей: Каждый модуль управляет своими зависимостями независимо, что позволяет избежать конфликтов версий между разными проектами на одном компьютере.

    2. Воспроизводимые сборки: Файлы go.mod (файл конфигурации модуля) и go.sum (содержит криптографические контрольные суммы для проверки целостности зависимостей), которые входят в состав модуля, гарантируют, что любой, кто клонирует ваш репозиторий, сможет собрать проект с теми же версиями зависимостей, что и у вас.

    3. Упрощенное управление версиями: Модули позволяют легко указывать минимальные требуемые версии зависимостей, а также использовать псевдонимы для различных версий или даже заменять модули локальными версиями для разработки.

    4. Децентрализованная разработка: Go может загружать зависимости из различных источников, включая системы контроля версий, таких как GitHub.

## 6.2 Основные операции с модулями Go

- Команда go env используется для просмотра и изменения настроек окружения (переменных),
которые управляют работой инструментария Go.

- `go.mod`: Этот файл объявляет путь к модулю, версию Go, используемую в проекте, и список всех зависимостей с их минимальными требуемыми версиями.

- `go.sum`: Содержит криптографические хеши содержимого всех зависимостей. Это обеспечивает безопасность и воспроизводимость, гарантируя, что загруженные модули не были подделаны.

1. Инициализация модуля. Чтобы превратить проект (каталог) в модуль, в корневом каталоге проекта надо выполнить команду:

- `go mod init [имя_модуля]`

1. Добавление зависимостей. При импорте новых пакетов в код программы и запуске команд go build или go test, Go автоматически добавит все необходимые зависимости в файл go.mod. Но также можно добавить зависимость вручную с помощью команды:

- `go get [путь_к_пакету]@[версия]`

1. Удаление неиспользуемых зависимостей. Со временем в вашем go.mod могут накопиться неиспользуемые зависимости. Их можно удалить командой:

- `go mod tidy`

    Эта команда также добавит недостающие зависимости.

1. Обновление зависимостей. Для обновления всех зависимостей до последних минорных или патч-версий (сохраняя мажорную версию), применяется команда:

- `go get -u`

    Для обновления до конкретной версии:

- `go get [путь_к_пакету]@latest`

- Для создания модуля применяется команда `go mod init [модуль]`

## 6.3 Видимость функций для других пакетов и вложенность пакетов

- Функции должны начинаться с заглавной буквы, чтобы их можно было использовать в других пакетах. Если определим функцию с маленькой буквы, например, hello_en, то другие пакеты ее не увидят.

- Можно создавать пакеты внутри пакета. Папка messages, в ней две папки messages_en и messages_ru, а в каждом пакете по файлу.

## 6.3 Внешние зависимости

- Внешние зависимости представляют сторонние библиотеки или пакеты кода, написанные другими разработчиками, которы можно использовать в своем проекте для добавления функциональности без необходимости писать ее с нуля.

- Загрузка зависимостей:
    `go get [имя зависимости]`, например, `go get rsc.io/quote`

- Все загужаемые пакеты хранятся в локальном кеше модулей, который расположен по пути, задаваемой переменной $GOMODCACHE (это же путь $GOPATH/pkg/mod). По умолчанию GOPATH устанавливается на подкаталог go в домашнем каталоге пользователя

- После загрузки зависимости будут обновлены файлы go.mod и go.sum (если этот файл отсутствует, то он создается).

- Файл `go.sum` содержит криптографические контрольные суммы для каждой загруженной версии модуля и его косвенных зависимостей (в данном случае rsc.io/sampler), обеспечивая целостность и безопасность.

- Со временем и развитием проекта какие-то зависимости могут оказаться не нужными, мы можем перестать их использовать. Тем не менее их метаданные по прежнему будут записаны в файлах go.mod и go.sum. Чтобы очистить проект от неиспользуемых в коде зависимостей, применяется команда go mod tidy. Она сканирует весь код и делает две вещи:

    1. Удаляет из go.mod и go.sum записи о зависимостях, которые не используются ни в одном import.

    2. Добавляет недостающие зависимости, если они импортированы с помощью инструкции import, но не загружены с помощью go get.

## 6.4 Управление зависимостями

В Go, как и в любом другом современном ЯП, существует механизм управления зависимостями - стронними библиотеками (пакетами), которые используются в проекте.

Одним из механизмов управления зависимостями в Go является использование папки **vendor**

Папка vendor представляет каталог в корневой папке проекта, в котором хранятся точные копии исходного кода всех зависимостей. Когда собирается или запускается проект, утилита Go в первую очередь ищет необходимые пакеты в этой папке, и только потом в глобальном кеше модулей ($GOPATH/pkg/mod)

Основные преимущества использования vendor:

- **Воспроизводимость сборок:** проект всегда будет собираться с одними и теми же версиями зависимостей, даже если их авторы внесут изменения или удалят свои репозитории.
- **Работа в офлайн-режиме:** так как весь необходимый код располагается локально, можно продолжать разработку и сборку проекта без доступа к интернету.
- **Контроль и аудит:** полный контроль над кодом зависимостей, можно проводить его аудит на безопасность и даже вносить исправления при необходимости.
- **Упрощение CI/CD:** процессы непрерывной интеграции и развертывания становятся проще и быстрее, так как не требуют скачивания зависимостей из сети на каждом шаге.

### 6.4 Как использовать vendor

Современный и рекомендуемый способ управления зависимостями в Go представляет использование модулей. Они позволяют легко интегрировать механизм работы с каталогом vendor.

Чтобы "завендорить" (скопировать) все зависимости из глобального кеша в локальную папку vendor, нужно выполнить команду: `go mod vendor`

### 6.4 Сборка проекта с использование vendor

Начиная с Go 1.14, если в проекте присутствует папка vendor, то команды `go build`, `go run` и другие команды сборки **автоматически** используют ее по умолчанию. Никаких дополнительных флагов не требуется. Если мы хотим явно указать компилятору использовать vendor, то можно использовать флаг -mod=vendor:

- `go run . -mod=vendor`

- `go build . -mod=vendor`

Это может быть полезно для старых версий Go или для того, чтобы убедиться, что сборка не обращается к сети.

### 6.4 Частые вопросы при работе с папкой vendor

1. Стоит ли коммитить папку vendor в Git?
    - **Да**, если разрабатывается приложение (конечный бинарный файл), и **нет**, если разрабатывается библиотека
    - **Для приложений**: Коммит папки vendor в систему контроля версий (например, Git) гарантирует максимальную воспроизводимость. Любой разработчик, склонировав репозиторий, получит те же самые зависимости без необходимости их скачивать. Это также упрощает сборку в CI/CD системах. Основной минус — увеличение размера репозитория.
    - **Для библиотек**: Коммитить vendor не рекомендуется, так как это может привести к конфликтам зависимостей в проектах, которые будут использовать вашу библиотеку. Лучше позволить конечному приложению самому решать, какие версии зависимостей использовать.

2. Как обновить зависимости?
    - Обновить нужную зависимость с go get: `go get -u rsc.io/quote`
    - Привести файлы go.mod и go.sum в соответствие с новой версией библиотеки: `go mod tidy`
    - Обновить содержимое папки vendor в соответствии с go.mod: `go mod vendor`

## 6.5 Создание разделяемого модуля

Возможно на каком-то этапе развития проекта мы захотим выделять некоторый функционал в отдельный модуль, которые можно повторно использовать в других проектах. То есть создать разделяемый модуль.

## 10.1 Изоморфная обработка ошибок

В Go ошибки обрабатываются либо с помощью возвращаемых значений, либо через механизм panic.

Обработка ошибок с помощью возвращаемых значений на примере открытия не существующего файла:

```
package main 
import (
    "fmt"
    "os"
)
 
func main(){
 
    file, err := os.Open("./content.txt") 
    fmt.Println("file :", file) 
    fmt.Println("error:", err)
}
```

Пример:

```
package main
import  "fmt"
 
func factorial(n int) (int, interface{}){
 
    // если переданное число меньше 0
    if(n < 0){
        return 0, "Недопустимое число. Должно быть больше 0"
    }
     
    result := 1
    for i := 1; i <= n; i +=1{
        result *= i
    }
    return result, nil
}
 
func main(){
 
    // Корректный параметр
    fact, err := factorial(5)
    fmt.Println("Factorial:", fact)     // Factorial: 120
    fmt.Println("Error:", err)  // Error: <nil>
 
    // Некорректный параметр
    fact, err = factorial(-5)
    fmt.Println("Factorial:", fact)     // Factorial: 0
    fmt.Println("Error:", err)  // Error: Недопустимое число. Должно быть больше 0
}
```

Это общий механизм, где, конечно, конкретная логика и возвращаемые типы могут отличаться в зависимости от наших потребностей, но в общем случае возвращаются два значения, где одно из них представляет информацию об ошибке, а второе - собственно результат функции.

## 10.2 Тип error

Для обработки ошибок язык Go предоставляет специальный интерфейс - error, который содержит один метод Error с возвращаемым типом string.

```
type error interface{
 
    Error() string
}
```

Значение по умолчанию для типа error - nil. Тип ошибки определяется следующим образом.

Любой тип, реализующий интерфейс error, может представлять тип ошибки:

```
package main 
import "fmt"
 
type param_error struct{}
 
// реализуем интерфейс error для типа param_error
func (error_object param_error) Error() string{ 
 
    return "Invalid parameter"
}
 
func main(){
 
    obj := param_error{}
    fmt.Println(obj.Error())    // Invalid parameter
 
    fmt.Println(param_error{})   // Invalid parameter
}
```

Применение данного интерфейса:

```
package main 
import "fmt"
 
type param_error struct{}
 
func (error_object param_error) Error() string{ 
 
    return "Invalid parameter"
}
 
func factorial(n int) (int, error){
 
    // если некорректный параметр
    if(n < 0){
        return 0, param_error{}
    }
     
    result := 1
    for i := 1; i <= n; i +=1{
        result *= i
    }
    return result, nil
}
 
func main(){
 
    // Корректный параметр
    fact, err := factorial(5)
    fmt.Println("Factorial:", fact)     // Factorial: 120
    fmt.Println("Error:", err)  // Error: <nil>
 
    // Некорректный параметр
    fact, err = factorial(-5)
    fmt.Println("Factorial:", fact)     // Factorial: 0
    fmt.Println("Error:", err)  // Error: Invalid parameter
}
```

1. В данном случае определяем функцию factorial, которая возвращает факториал числа. Причем в реальности возвращается два значения - целое число и ошибку в виде объекта error

2. Если n < 1, возвращает 0 и объект param_error, сигнализируя о некорректном параметре

3. Иначе вычисляет факториал n в цикле и возвращает результат и nil как ошибку

4. Функция main выполняет два вызова factorial. В первом случае передается валидное число 5

5. Во втором случае передается некорректное число -5, поэтому переменная err будет представлять информацию об ошибке в виде объекта param_error

### Пакет error

В стандартной библиотеке языка Go имеется встроенный пакет **errors**, который реализует различные функции для управления ошибками. Он имеет функцию под названием **New()**, которая возвращает объект интерфейса error и устанавливает его сообщение об ошибке.

```
package main
import (
    "fmt"
    "errors"
)
 
func factorial(n int) (int, error){
 
    if(n < 0){
        return 0, errors.New("недопустимое число: должно быть положительным")
    }
     
    result := 1
    for i := 1; i <= n; i +=1{
        result *= i
    }
    return result, nil  // Возвращаем nil в качестве ошибки, если все хорошо
}
 
func main(){
 
    // Корректный параметр
    fact, err := factorial(5)
    fmt.Println("Factorial:", fact)     // Factorial: 120
    fmt.Println("Error:", err)  // Error: <nil>
 
    // Некорректный параметр
    fact, err = factorial(-5)
    fmt.Println("Factorial:", fact)     // Factorial: 0
    fmt.Println("Error:", err)  // Error: недопустимое число: должно быть положительным
}
```

## 10.3 Оператор defer и отложенное выполнение функций

Оператор **defer** позволяет выполнить определенную функцию в конце окружающей функции. Обычно с помощью оператора defer выполняются операции очистки, например, закрытие файлов, или какие-то действия, которые должны быть выполнены в самом конце.

Оператор defer работает следующим образом:

- Оператор defer помещает вызов переданной ему функции в стек. Когда окружающая функция возвращает управление, вызываются все функции, хранящиеся в стеке. Функция, хранящаяся в конце стека, выполняется первой. Значения, переданные в аргументах функции defer, вычисляются, когда компилятор находит оператор defer.

- В функциях defer могут выполняться как операции чтения, так и записи.

- Возвращаемые значения могут быть изменены в функциях defer.

- Оператор defer обеспечивает выполнение отложенных функций даже в случае ошибки или вызова функции panic, помогая очищать ресурсы.

```
package main
import "fmt"
 
func main() {
    defer finish()
    fmt.Println("Program has been started")
    fmt.Println("Program is working")
}
 
func finish(){
    fmt.Println("Program has been finished")
}
```

Здесь функция finish вызывается с оператором defer, поэтому данная функция в реальности будет вызываться в самом конце выполнения программы, несмотря на то, что ее вызов определен в начале функции main.

Если несколько функций вызываются с оператором defer, то те функции, которые вызываются раньше, будут выполняться позже всех.

```
package main
import  "fmt"
 
func main() {
      
    defer finish()
    defer fmt.Println("Program has been started")
    fmt.Println("Program is working")
}
 
func finish(){
    fmt.Println("Program has been finished")
}
```

Вывод:

Program is working
Program has been started
Program has been finished


Более практический пример:

```
package main
 
import (
    "fmt"
    "os"
)
 
func open_file(){
 
    // открываем файл
    file, err := os.Open("./main.go") 
    // закрываем файл в конце функции
    defer file.Close()
    // работа с файлом
    fmt.Println("file:", file)
    fmt.Println("error:", err)
}
 
func main(){
 
    open_file()
}
```

### Оператор panic

Оператор **panic** представляет еще один способ обработки ошибок. Он позволяет сгенерировать ошибку и выйти из программы. Он используется для проверики непредвиденных ошибок во всей программе и чем-то похож на исключения в других ЯП. Всякий раз, когда в любой функции вызывается оператор **panic**, он останавливает выполнение этой функции и завершает выполнение программы. Но если в функции, где произошла ошибка, вызываются функции с оператором defer, то перед завершением программы выполняются эти функции.

В качестве параметра оператор **panic** примнимает произвольное значение (формально интерфейс interface(), к которому в реальности соответствует произвольное значение)

`panic (interface {})`

Пример применения:

```
package main
import "fmt"
 
func main() {
    fmt.Println(divide(15, 5))
    fmt.Println(divide(4, 0))
    fmt.Println("Program has been finished")
}
func divide(x, y float64) float64{
    if y == 0{ 
        panic("Division by zero!")
    }
    return x / y
}
```

В данном случае в фукнции divide, если второй параметр равен 0, то осуществляется вызов panic("Division by zero!")

В некоторых случаях мы можем выполнить некоторую очистку или другую необходимую операцию, прежде чем программа завершится. Это можно сделать, используя функцию с оператором **defer**, которая выполняется перед завершением программы.

```
package main
import "fmt"
 
func divide_defer(){
 
    fmt.Println("divide_defer executed")
}
 
func main_defer(){
 
    fmt.Println("main_defer executed")
}
 
 
func divide(x, y float64) float64{
    defer divide_defer()
    if y == 0{ 
        panic("Division by zero!")
    }
    return x / y
}
 
func main() {
    defer main_defer()
    fmt.Println(divide(4, 0))
    fmt.Println("Program has been finished")
}
```

## 10.4 Восстановление после ошибки и функция recover

Для обработки ошибок, сгенерированных функцией panic, Go предоставляет встроенную функцию **recover()**. Эта функция может служить некоторой аналогией для конструкций try-catch в других языках. Функция **recover** используется внутри функции defer (поскольку после вызова panic выполняются только операторы defer). Функция **recover** возвращает значение, переданное через panic. Если в программе не было вызовов panic, или recover() был вызван не в отложенной функции, то recover() возвращает nil.

Пример кода с делением на ноль:

```
package main
import "fmt"
 
func try_catch(){
 
    if r := recover(); r != nil { 
        fmt.Println("Error:", r) 
    }
}
 
func divide(x, y float64) float64{
    defer try_catch()
    if y == 0{ 
        panic("Division by zero!")
    }
    return x / y
}
 
func main() {
    fmt.Println(divide(4, 0))
    fmt.Println("Program has been finished")
}
```

Эта программа на Go демонстрирует механизм обработки ошибок, похожий на try-catch в других языках программирования, но реализованный с использованием встроенных функций Go: defer, panic и recover.

Прежде всего для перехвата ошибки, которая сгенерирована оператором panic() определена функция try_catch()

1. Вначале проверяем был ли вызов panic:
`if r := recover(); r != nil { ... }`

2. Выражение r := recover() пытается перехватить вызов panic() и присваивает результат функции переменной r. Далее выражение if r != nil проверяет, был ли вызов panic(). Если r не равно nil, это означает, что был вызов panic() и он успешно перехвачен.

3. В конце выводим сообщение об ошибке вместе со значением, переданным в panic (в данном случае "Division by zero!"):
`fmt.Println("Error:", r)`

4. Далее идет функция divide(), в которой собственно и генерируется ошибка при делении на ноль.
    ```
    func divide(x, y float64) float64{
        defer try_catch()
        if y == 0{ 
            panic("Division by zero!")
        }
        return x / y
    }
    ```

5. Для перехвата ошибки вначале идет вызов defer try_catch(). То есть функция try_catch будет вызвана непосредственно перед тем, как функция divide завершит свое выполнение, независимо от того, произошла ли ошибка.

6. Далее проверяем, равен ли делитель (y) нулю. Если да, то вызывается panic() со строковым сообщением "Division by zero!":
`if y == 0 { panic("Division by zero!") }`

7. panic останавливает нормальное выполнение программы и начинает раскручивать стек вызовов, выполняя все отложенные defer-функции. В функции main() происходит вызов функции divide с аргументами 4 и 0:
`fmt.Println(divide(4, 0))`

8. Поскольку y равно 0, функция divide вызовет panic. В итоге этот вызов будет перехвачена функцией try_catch (которая была отложена), и на экран будет выведено сообщение "Error: Division by zero!". Консольный вывод:
    ```
    Возникла ошибка: Division by zero!
    0
    Program has been finished
    ```

Если суммировать, то мы получим следующую последовательность действий:

1. Вызывается main(), затем divide(4, 0).

2. Внутри divide, defer try_catch() откладывает выполнение try_catch до выхода из divide.

3. Условие y == 0 истинно, поэтому вызывается panic("Division by zero!").

4. Начинается раскрутка стека. Прежде чем divide полностью завершится, срабатывает отложенная функция try_catch().

5. Внутри try_catch(), recover() перехватывает значение паники ("Division by zero!").

6. fmt.Println("Error:", r) выводит "Error: Division by zero!".

7. Поскольку вызов panic() был перехвачен, программа продолжает выполнение из main().

8. Выводится "Program has been finished".
