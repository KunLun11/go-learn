## Как пользоваться

1. Утром открываешь файл текущей недели и читаешь блок «Итоги недели».
2. В течение дня идёшь по дням: теория → практика → закрепление → проект.
3. Вечером отмечаешь чекбоксы и пишешь 3 строки в `../learning-log.md`.
4. В конце недели проходишь «Гейт недели». Не закрыл — урезаешь объём, но не переносишь
   долг в следующую неделю.

## Дисциплина

- Каждый день — минимум один коммит.
- Каждый день — 3 строки в `learning-log.md`.
- Каждая непонятная ловушка — в `go-gotchas.md` с примером и выводом.
- Любой код, который не проходит `go vet` и `gofmt`, не считается готовым.
